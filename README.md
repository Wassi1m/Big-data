# Uber Big Data Stack

Pipeline Big Data avec Docker Compose.

## Stack technique
Kafka + Zookeeper · Kafka UI · Elasticsearch · Logstash · Kibana · PySpark (Jupyter)

## Lancement
docker compose up -d

## Accès local
- Kafka UI : http://localhost:8085
- Kibana : http://localhost:5601
- Elasticsearch : http://localhost:9200
- Jupyter : http://localhost:8888 (token : admin)
- Spark UI : http://localhost:4040
